# 📊 SQL Practice Journey

This repository documents my journey of learning and mastering SQL through structured practice, conceptual revision, and interview preparation.

I started with topic-wise SQL practice to build strong fundamentals, understand individual concepts, and develop effective problem-solving techniques. Having completed this phase, I am now moving towards mixed SQL practice to strengthen my ability to solve complex, real-world problems by combining multiple concepts.

## 📚 Topics Covered

- SQL Fundamentals: SELECT, DDL, DML, Filtering
- Joins and Aggregations
- String Functions and Date & Time Functions
- NULL Handling and Conditional Expressions
- Subqueries and Common Table Expressions (CTEs)
- Window Functions
- Views, CTAS, and Temporary Tables
- Stored Procedures and Triggers
- Indexes and Query Performance Fundamentals

## 🎯 Learning Approach

- **Topic-wise Practice:** Build a strong foundation by solving problems focused on individual SQL concepts.
- **Theoretical Revision:** Strengthen conceptual understanding through interview-style questions and explanations.
- **Mixed SQL Practice:** Apply multiple concepts together to solve more complex problems without relying on topic-specific prompts.

## 🚀 Current Focus

Transitioning from topic-wise practice to mixed SQL problem-solving, with an emphasis on query logic, selecting appropriate approaches, writing efficient queries, and developing interview-ready problem-solving skills.

## 🧠 What This Repository Demonstrates

- Consistent, structured learning and practice
- Practical application of SQL concepts
- Conceptual understanding of SQL and database fundamentals
- A continuous effort to improve query-writing and problem-solving skills
